# Native Scroll

Native Scroll 是一款 Chrome 扩展，用于阻止网页擅自接管滚轮或触控板手势，让滚动体验尽量保持 Chrome 与操作系统原有的手感，同时保留页面内的普通控件和可滚动区域。

## 主要功能

- 一键开启或关闭所有网站的滚动保护
- 标准模式兼顾滚动体验与网页兼容性
- 强力模式处理持续运行的脚本滚动和模拟页面移动
- 支持单个主机名与通配符白名单
- 仅在当前页面的滚动代码确实被拦截后，才在工具栏图标上显示状态
- 极简控制窗口，并自动适配系统的浅色或深色外观
- 提供自然的 en-US 与 zh-CN 界面
- 完全在本地运行，不使用分析服务，也不发送网络请求
- 轻量运行，不轮询、不扫描整个页面，也不常驻后台页面

## 安装

1. 克隆或下载本仓库。
2. 在 Chrome 中打开 `chrome://extensions`。
3. 开启**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择本项目的 [`extension`](extension) 文件夹。

Chrome 可能会询问是否允许扩展访问网站。Native Scroll 需要访问 HTTP 与 HTTPS 页面，才能在网页自己的滚动代码开始运行前提供保护。

## 使用方法

打开工具栏中的控制窗口即可使用以下功能：

- **电源图标**：在所有网站上开启或关闭保护。
- **闪电图标**：切换标准模式与强力模式。
- **盾牌图标**：将当前主机名加入或移出白名单。
- **设置图标**：管理界面语言、保护模式和白名单。

Native Scroll 在当前页面拦截滚动代码后，工具栏图标上会出现蓝色圆点。离开该页面、关闭保护或将网站加入白名单后，圆点会消失。

### 保护模式

**标准模式**为默认选项。它会阻止网页接管整页的纵向滚轮和触控板手势，同时保留双指缩放、以横向为主的手势、交互控件以及普通的页面内滚动区域。

**强力模式**适用于通过脚本模拟页面移动，或反复恢复自定义滚动行为的网站。它的处理范围更广，可能影响结构复杂的交互页面，因此日常使用仍建议选择标准模式。

### 白名单

`example.com` 仅匹配该主机名。`*.example.com` 会同时匹配根域名及其所有子域名。控制窗口添加的是当前页面的精确主机名；通配规则可在设置页面管理。

## 隐私

Native Scroll 完全在您的设备上运行，仅保存开启状态、保护模式、界面语言和白名单。插件不会收集浏览记录，不使用分析服务，也不会发送网络请求。

## 兼容性

本插件适用于 Chrome 120 及以上版本，主要针对 macOS 触控板的滚动体验设计，同时支持 Windows 与 Linux 版 Chrome 的滚轮和触控滚动。

Chrome 不允许扩展在 `chrome://`、Chrome 应用商店和部分内置查看器中运行，因此 Native Scroll 不会处理这些页面。
