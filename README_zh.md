# Cosmic Gemini

[English](README.md)

Cosmic Gemini 是一款包含两项独立功能的 Chrome 扩展。Native Scroll 让滚轮和触控板尽量保持浏览器与操作系统原有的滚动体验；No Autoplay 则会阻止网页在未经您操作的情况下播放视频或声音。

## 功能介绍

### Native Scroll

Native Scroll 会拦截网页对滚轮和触控板手势的接管，同时保留普通控件和页面内可滚动区域的正常操作。标准保护适合日常使用；对于反复恢复自定义滚动或通过脚本模拟页面移动的网站，可以单独开启强力保护。

### No Autoplay

No Autoplay 会阻止未经您操作便开始播放的视频和声音，您主动播放的媒体仍可正常使用。网站尝试自动播放声音时，页面右上角会询问您是继续拦截、本次允许还是永久允许。声音权限仅适用于音频元素和 Web Audio，自动播放的视频仍会被拦截。

如果您希望某些网站完全不加载媒体元素，可以为这些网站开启强力保护。页面加载后新增的视频和音频也会被移除。

## 主要特性

- 两项功能分别管理开关、白名单和强力模式网站
- 支持 `example.com` 这样的精确主机名，以及 `*.example.com` 这样的通配规则
- 在极简控制窗口中分别管理当前页面的两项功能
- Native Scroll 与 No Autoplay 各有独立设置页面，并可直接切换
- 只有任一功能在当前页面实际执行拦截后，工具栏图标才会变化
- 提供自然的 en-US 与 zh-CN 界面，并自动适配系统的浅色或深色外观
- 采用事件驱动，不轮询，也不常驻后台页面
- 完全在本地运行，不使用分析服务，也不发送网络请求

## 安装

1. 克隆或下载本仓库。
2. 在 Chrome 中打开 `chrome://extensions`。
3. 开启**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择本项目的 [`extension`](extension) 文件夹。

Chrome 会要求扩展访问 HTTP 与 HTTPS 页面，以便两项保护在普通网页脚本运行前开始工作。

## 使用方法

控制窗口中，Native Scroll 与 No Autoplay 各占一行。每一行均包含以下操作：

- **电源图标**：在所有网站上开启或关闭该项功能
- **闪电图标**：为当前主机名开启或关闭强力保护
- **网站图标**：将当前主机名加入或移出该项功能的白名单
- **设置图标**：打开对应的设置页面

某项功能适用于当前页面时，其功能图标会显示为绿色。控制窗口中的 Cosmic Gemini 主标志不会变化；只有功能实际拦截网页行为后，Chrome 工具栏中的小图标才会切换状态。

### 网站规则

`example.com` 仅匹配该主机名；`*.example.com` 同时匹配根域名及其所有子域名。控制窗口添加的是精确主机名，设置页面还可以添加通配规则。白名单的优先级高于强力模式网站规则。

### 临时声音权限

选择**本次允许**后，该权限会持续到该主机名下的所有页面全部关闭，或自授权起满两天，以较早发生的时间为准。临时权限随后会自动删除。选择**永久允许**后，该规则会保留在 No Autoplay 设置中，直至您手动移除。

## 隐私

Cosmic Gemini 完全在您的设备上运行，仅保存两项功能的设置、您选择的网站规则，以及仍在有效期内的临时声音权限。插件不会记录浏览历史或活动记录，不使用分析服务，也不会发送网络请求。保存的网站规则仅包含主机名，不包含完整网址。

## 兼容性

Cosmic Gemini 适用于 Chrome 120 及以上版本，支持 macOS、Windows 和 Linux。Native Scroll 针对触控板与滚轮操作设计；No Autoplay 支持普通网页使用的 HTML 媒体和 Web Audio。

Chrome 不允许扩展在 `chrome://`、Chrome 应用商店和部分内置查看器中运行，因此 Cosmic Gemini 不会处理这些页面。

## 开发

Cosmic Gemini 使用 Manifest V3，没有运行时依赖。项目架构参见 [技术设计](docs/TECHNICAL.md)，精简验证流程参见 [验证说明](docs/QA.md)。

