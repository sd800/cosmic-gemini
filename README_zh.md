# Cosmic Gemini

[English](README.md)

Cosmic Gemini 是一套个人使用的 Chrome 网页工具，让日常浏览更清爽、更可控。插件包含三项相互独立的功能：Native Scroll、No Autoplay 和 Any Copy。

## 功能介绍

### Native Scroll

Native Scroll 会拦截网页对滚轮和触控板手势的接管，同时保留普通控件和页面内可滚动区域的正常操作。增强模式适合处理反复恢复自定义滚动，或通过脚本模拟页面移动的网站。

### No Autoplay

No Autoplay 会阻止未经您操作便开始播放的视频和声音，您主动播放的媒体仍可正常使用。网站尝试自动播放声音时，您可以继续拦截、本次允许或永久允许该网站播放声音。增强模式会移除指定网站中的媒体元素。

### Any Copy

Any Copy 会恢复被网页禁用的文字选择与复制快捷键，并阻止网页替换复制内容或在其中加入推广文字。增强模式会将网页整理为简洁的静态阅读页面，文字可自由选择，图片也不会被遮挡。原网页会保留在下方，退出增强模式后即可立即恢复。

## 主要特性

- 三项功能分别管理各自的操作与网站规则
- 支持 `example.com` 这样的精确主机名，以及 `*.example.com` 这样的通配规则
- 在极简控制窗口中管理当前页面
- 三项功能各有独立设置页面，并可直接切换
- 提供自然的 en-US 与 zh-CN 界面，并自动适配系统的浅色或深色外观
- 采用事件驱动，不轮询，也不常驻后台页面
- 完全在本地运行，不使用分析服务，不记录浏览历史，也不发送网络请求

## 安装

1. 克隆或下载本仓库。
2. 在 Chrome 中打开 `chrome://extensions`。
3. 开启**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择本项目的 [`extension`](extension) 文件夹。

Chrome 会要求扩展访问 HTTP 与 HTTPS 页面，以便各项功能在普通网页脚本运行前开始工作。

## 使用方法

控制窗口中，每项功能各占一行。

- Native Scroll 与 No Autoplay 提供**开关**、**增强模式**、**白名单**和**设置**按钮。
- 点击 Any Copy 的功能图标，即可为当前网站开启或关闭该功能。您也可以在关闭状态下直接进入**增强模式**，并在设置中管理执行网站与增强模式网站。
- 如果 Any Copy 从关闭状态直接进入增强模式，退出增强模式时会直接关闭。如果先开启普通模式再进入增强模式，退出后则会回到普通模式。

Native Scroll 与 No Autoplay 的功能图标在关闭或不适用时显示为中性色，开启后显示为蓝色，在当前页面实际执行拦截后显示为绿色。Any Copy 不使用蓝色状态：为当前网站开启后即显示为绿色。控制窗口中的 Cosmic Gemini 主标志不会变化。

### 网站规则

`example.com` 仅匹配该主机名；`*.example.com` 同时匹配根域名及其所有子域名。控制窗口保存的是当前页面的精确主机名，设置页面还可以添加通配规则。对于 Native Scroll 与 No Autoplay，白名单的优先级高于增强模式网站规则。

### 临时声音权限

选择**本次允许**后，该权限会持续到该主机名下的所有页面全部关闭，或自授权起满两天，以较早发生的时间为准。临时权限随后会自动删除。选择**永久允许**后，该规则会保留在 No Autoplay 设置中，直至您手动移除。

## 隐私

Cosmic Gemini 完全在您的设备上运行，仅保存各项功能的设置、您选择的网站规则，以及仍在有效期内的临时声音权限。插件不会记录浏览历史或活动记录，不使用分析服务，也不会发送网络请求。保存的网站规则仅包含主机名，不包含完整网址。

## 兼容性

Cosmic Gemini 适用于 Chrome 120 及以上版本，支持 macOS、Windows 和 Linux。Chrome 不允许扩展在 `chrome://`、Chrome 应用商店和部分内置查看器中运行，因此 Cosmic Gemini 不会处理这些页面。

## 开发

Cosmic Gemini 使用 Manifest V3，没有运行时依赖。项目架构参见 [技术设计](docs/TECHNICAL.md)，精简验证流程参见 [验证说明](docs/QA.md)。

npm run check
