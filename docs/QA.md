# Verification

## Automated checks

From the project directory, run:

```sh
npm test
npm run check
```

The focused suite covers configuration isolation, current-site overrides, exact and wildcard rule precedence, independent Any Copy runtimes, No Autoplay audio permission, direct media-play intent, Mailto Capture parsing and lifecycle cleanup, XHS text-image classification and photographic preservation, image grouping and original-source ranking, download-discovery lifecycle states, Bilibili calendar-day handling, locale selection, page runtimes, Manifest V3 permissions, local-only assets, script syntax, and interface constraints.

## Chrome checks

1. Open `chrome://extensions`, enable Developer mode, and load the `extension` folder as an unpacked extension.
2. Open the popup and confirm that it contains four paired rows: Native Scroll with Native Scroll Enhanced, No Autoplay with No Autoplay Enhanced, Any Copy with Any Copy Enhanced, and Image Download with Video Download. Confirm that the product icons are slightly larger than the All Settings icon, the Cosmic Gemini wordmark is hidden, and All Settings occupies a separate bottom row aligned to the right.
3. Confirm that inactive primary products use a stronger neutral color than Enhanced controls. Active Native Scroll, No Autoplay, Any Copy, and Any Copy Enhanced controls must be blue with a background. Active Image Download and Video Download controls must be blue without a background. Confirm that dark mode uses the brighter blue throughout the popup, settings pages, and download workspaces without changing the light-mode color. Solid blue buttons must retain readable foreground text. After Native Scroll or No Autoplay actually intervenes, confirm that the active Standard or Enhanced control gains a thin blue outline.
4. Turn the Native Scroll global default off in Settings, then activate it from the popup on one website. Confirm that an exact Always Standard rule keeps that website active. Turn the global default on, make the same website inactive from the popup, and confirm that its exact Always inactive rule takes priority. Repeat with No Autoplay.
5. Add `*.example.com` under Always use Enhanced mode, then turn Enhanced off on a matching exact hostname. Confirm that the website receives an exact Always use Standard mode rule. Turn Enhanced on while the global product default is off and confirm that the exact website becomes active in Enhanced mode.
6. Open all six product settings pages and the All Settings page. Refresh them quickly and switch among them. Confirm that the structure, cached control values, and en-US or zh-CN copy appear together without a blank or wrong-language frame. Confirm that the first introduction card on every page uses the same blue-tinted border. Confirm that All Settings remains the rightmost settings-page switch and that its six product cards open the correct pages.
7. From All Settings, choose Reset all settings and cancel once. Confirm that nothing changes. Confirm the next attempt and verify that product defaults, website rules, explicit language choice, active image and video sessions, and temporary toolbar state are reset while already-downloaded files remain available.
8. On a page with a wheel takeover handler, confirm that Native Scroll preserves browser scrolling and that the browser toolbar activity artwork can still change independently from the popup's blue state model.
9. 10. Add a website to the shared whitelist from Native Scroll settings and confirm that the same rule appears in No Autoplay settings. Remove the rule from No Autoplay settings and confirm that it disappears from both pages and the previously saved product-specific behavior resumes. Confirm that click-activated products remain available when explicitly started.
